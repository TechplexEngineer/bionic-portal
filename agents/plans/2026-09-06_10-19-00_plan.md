# Remember Login Redirect Implementation Plan

## Goal

Preserve the internal page an unauthenticated user requested and return them there after successful magic-link authentication.

## Design

- Secure layouts add the current pathname and query string to `/login?next=...`.
- The login form and magic-link verification form carry a sanitized `next` value through the flow.
- A server-only helper accepts same-origin relative paths and falls back to `/dashboard` for missing or external values.
- Verification redirects to the validated path after creating the session.
