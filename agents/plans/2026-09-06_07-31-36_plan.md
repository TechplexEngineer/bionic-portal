# Fix event deletion cancellation

## Goal

Ensure choosing Cancel in the admin event deletion confirmation leaves the event unchanged and does not start the enhanced form submission state.

## Steps

- [x] Inspect the delete form and identify why cancellation still reaches the delete action.
- [x] Move confirmation into the SvelteKit enhancement callback so cancellation explicitly cancels enhanced submission before any loading state is set.
- [x] Add a regression test proving the delete form cancels before entering its deleting state.
- [x] Run focused tests, formatting/lint checks, and the repository checks that are relevant to the touched files.
- [x] Record verification results and review notes.
