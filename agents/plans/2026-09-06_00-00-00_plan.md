## Proposed configuration

The revised configuration will call helper scripts:

```json
{
  "setup": ["./.superset/setup.sh"],
  "teardown": ["./.superset/teardown.sh"],
  "run": ["./.superset/run.sh"]
}
```

`setup.sh` will run `npm ci` and copy `$SUPERSET_ROOT_PATH/.env` when present. `run.sh` will allocate a workspace-specific port, start the Vite dev server, and apply local D1 migrations with `npm run db:migrate:local`.
