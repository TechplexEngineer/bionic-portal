# Admin Student Cascade Delete Implementation Plan

**Goal:** Allow admins to permanently delete a student after reviewing and confirming the student’s related-record counts.

**Architecture:** Extend the existing `/admin/students` page load with counts for every record that will be cascaded. Add a `delete` page action that validates the submitted student ID, deletes dependent rows in foreign-key-safe order, and then deletes the student. The page will render a native confirmation dialog whose message is built from the loaded counts.

**Tech Stack:** SvelteKit, Svelte 5, TypeScript, Drizzle ORM with Cloudflare D1/SQLite, Vitest.
