# Production Database Fixture Plan

**Goal:** Create a local-run fixture containing exactly five anonymized students and the events plus related records needed to exercise event flows.

**Approach:** Export the Cloudflare D1 production database read-only into a temporary file, transform it with a checked-in Node script that allowlists tables and deterministically rewrites student-linked PII and payment/contact identifiers, then store only the sanitized SQL fixture and a local import command in the repository.

**Verification:** Apply migrations to a fresh local D1 database, import the fixture, assert five students, verify all foreign keys and selected event relationships, and scan the committed fixture for source student/contact values before commit.
