**Goal:** Convert the existing event-scoped admin forms page from an embedded creator into a forms list landing page.

**Architecture:** Keep the secure event route and existing server-side event/form loading unchanged. Remove list-page-only upload/editor state and the save action, and render Bootstrap list rows with field counts plus links reserved for later form creation/edit routes.

**Tech Stack:** SvelteKit, Svelte 5, TypeScript, Vitest, Bootstrap utility classes.
